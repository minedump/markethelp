# MarketHelp — новый сайт

Статический сайт на Next.js, который собирается из UI-кита.

```
web/        Сайт: Next.js 15, Tailwind, статический экспорт в out/
kit/        UI-кит: единственный источник оформления. Правится только он.
```

Рядом на диске, но вне репозитория (публичный гит — не место для
внутренних материалов и чужого прайса):

```
site/       Макет сайта одним файлом — то, из чего перенесён web/
pricelist/  Прайс-лист и его PDF
tilda/      Блок контактов с картой для нынешнего сайта на Tilda
sources/    ТЗ, тексты, аудит дизайна, переписка
```

## Правило

Ни одна страница не описывает оформление сама: кнопки, поля, таблицы,
заголовки, плитки — всё берётся из кита. Если элемента в ките нет —
он сперва появляется там, с пояснением зачем, и только потом на странице.

Кит перенесён в компоненты: `web/components/ui/` — те же классы, те же
пояснения. Слой стилей кита целиком лежит в `web/app/globals.css`;
оформление самого сайта (шапка, логотип, бегущая строка) — отдельным
блоком в конце того же файла, помеченным.

Содержание и тексты не живут в разметке: они в `web/content/`.
Неразрывные пробелы расставляются сами — `web/lib/typo.ts`.

## Сборка

```
cd web
npm ci
npm run dev        # localhost:3000
npm run build      # статический экспорт в web/out
```

Боевая сборка — с адресом сайта и включённым счётчиком:

```
NEXT_PUBLIC_SITE_URL=https://markethelp.ru NEXT_PUBLIC_METRIKA=1 npm run build
```

Переменные:

| Переменная               | Зачем                                                        |
| ------------------------ | ------------------------------------------------------------ |
| `NEXT_PUBLIC_SITE_URL`   | адрес для canonical, карты сайта и картинки ссылок            |
| `NEXT_PUBLIC_METRIKA=1`  | включает Яндекс Метрику и открывает сайт в `robots.txt`       |

Без переменных сборка считается тестовой: счётчика нет, а `robots.txt`
закрывает сайт целиком — чтобы поисковик не проиндексировал тестовый
домен и не склеил его с боевым.

## Проверки

```
cd web
npm run build
npm run check      # внутренние ссылки и якоря: ни одной битой
npm run kit-lint   # страницы не переопределяют кит
npx tsc --noEmit   # типы
```

Отдельно по киту, из корня:

```
node kit/check.js        # все фирменные цвета в классах существуют
node kit/tip-test.js     # геометрия подсказки, 12 случаев
```

## Прайс-лист в PDF

Файл лежит в сборке — `web/public/pricelist/`, на него ведут кнопки
«Скачать прайс в PDF» на страницах тарифов и услуг. Адрес задан один
раз, в `PRICELIST` (`web/content/pages.ts`).

Сам он не пересобирается. Цены на странице тарифов идут из
`web/content/prices.ts`, а PDF — из `pricelist/prices.py`; это два
отдельных файла с одними и теми же числами, и при правке цен нужно
пройти обе стороны, иначе сайт и скачанный прайс разойдутся:

```
# 1. поправить цены в обоих файлах
#    pricelist/prices.py   — для PDF
#    web/content/prices.ts — для сайта
# 2. пересобрать PDF и положить его в сборку
python pricelist/build.py && python pricelist/make-pdf.py
cp "pricelist/MarketHelp — прайс-лист 2026.pdf" web/public/pricelist/
```

## Перенос со старого сайта

Записи блога перенесены с Tilda в `web/content/blog.ts`. Карта
редиректов со старых адресов и порядок их установки — в
[REDIRECTS.md](REDIRECTS.md); ставятся на боевом домене.

## Что ещё не включено

- Заявка никуда не отправляется: приёмник появится вместе
  с `app.markethelp.ru`. Места отмечены в коде — `RequestModal.tsx`
  и `ContactForm.tsx`.
- Кнопка личного кабинета скрыта: `APP.ready` в `web/content/site.ts`.
- В блоге две записи — обе перенесены со старого сайта. Темы, под
  которые верстался макет, лежат планом в `PLANNED` (`web/content/blog.ts`):
  тексты и цифры в них были придуманы для показа вёрстки, публиковать
  такое нельзя. Написанная запись переезжает в `POSTS` и `ARTICLES`.
- В текстах остались пометки «уточнить» там, где ждём цифры от склада.
