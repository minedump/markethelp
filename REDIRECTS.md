# Карта редиректов со старого сайта

Старый сайт на Tilda и новый расходятся адресами: часть страниц
переименована, часть переехала, у блога другой вид ссылок. Чтобы ссылки
из поиска, писем и визиток не упирались в «Такой страницы нет», старые
адреса нужно перенаправить на новые — постоянным редиректом 301, чтобы
поисковик перенёс на новую страницу накопленный вес старой.

Ставятся редиректы **на боевом домене**, когда `markethelp.ru` будет
смотреть на новый сайт. На тестовом домене они не нужны: по этим
адресам туда никто не приходит.

## Что нужно настроить

Пять правил. Все — типа `path`, код `301`.

| Старый адрес                                             | Новый адрес                                   | Почему                                      |
| -------------------------------------------------------- | --------------------------------------------- | ------------------------------------------- |
| `/politika-konfidencialnosti`                              | `/policy/`                                    | политика переехала на латинский адрес        |
| `/kartochka-organizacii`                                   | `/requisites/`                                | карточка организации стала «Реквизитами»     |
| `/blanc`                                                   | `/tariffs/`                                   | акции «Тариф „Старт“ за 0 ₽» больше нет; ближайшее по смыслу — тарифы |
| `/blog/tpost/7usyr9xm2f-upakovka-tovarov-dlya-marketpleisov` | `/blog/upakovka-tovarov-dlya-marketpleisov/`  | статья перенесена, адрес без служебного кода Tilda |
| `/blog/tpost/g1gi9habe5-vistavka-ecom-expo20`              | `/blog/vistavka-ecom-expo20/`                 | то же                                        |

## Что настраивать не нужно

| Старый адрес | Что происходит                                                     |
| ------------ | ------------------------------------------------------------------ |
| `/`          | главная осталась главной                                            |
| `/tariffs`   | сайт сам отвечает `308` и ведёт на `/tariffs/`                      |
| `/blog`      | то же — `308` на `/blog/`                                           |
| `/contacts`  | то же — `308` на `/contacts/`                                       |

Адреса без завершающего слеша новый сайт перенаправляет сам: страницы
собраны со слешем, и сервер добавляет его постоянным редиректом. Эти
три правила только заняли бы место в лимите.

Если сайт открывается ещё и с `www`, добавьте шестое правило типа
`host`: источник `www.markethelp.ru`, назначение `markethelp.ru`,
код `301`. Два адреса одной страницы поисковик считает двумя сайтами.

## Как установить в Timeweb App Platform

1. Панель Timeweb Cloud → **App Platform** → приложение.
2. Вкладка **«Настройки»** → строка **«Настройки веб-сервера»**.
3. Раздел **«Редиректы»** → добавить правило:
   - **Тип** — `path` (для `www` — `host`);
   - **Source** — старый адрес из таблицы, начиная со слеша;
   - **Destination** — новый адрес;
   - **Code** — `301`.
4. Повторить для всех пяти правил и сохранить.

После сохранения приложение задеплоится само — пересобирать вручную
не нужно.

Ограничения панели, о которые легко споткнуться:

- не больше **10 редиректов** на приложение — у нас пять, запас есть;
- пути пишутся **со слеша в начале**;
- в путях **нельзя** указывать параметры после `?` и якоря после `#`;
  параметры исходного запроса сохраняются сами;
- источник и назначение не должны совпадать.

## Как проверить

После установки — каждый адрес должен отвечать `301` и вести на новый:

```bash
for u in /politika-konfidencialnosti /kartochka-organizacii /blanc \
         /blog/tpost/7usyr9xm2f-upakovka-tovarov-dlya-marketpleisov \
         /blog/tpost/g1gi9habe5-vistavka-ecom-expo20; do
  printf '%s ' "$u"
  curl -s -o /dev/null -w '%{http_code} -> %{redirect_url}\n' "https://markethelp.ru$u"
done
```

И отдельно — что несуществующий адрес по-прежнему отдаёт `404`, а не
заворачивается на главную:

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://markethelp.ru/net-takoy-stranicy/
```

## После переключения домена

- В Яндекс Вебмастере и Google Search Console отправить новую карту
  сайта: `https://markethelp.ru/sitemap.xml`.
- Там же проверить, что старые адреса показываются как перенесённые,
  а не как ошибки.
- Счётчик Метрики тот же — номер 66434122, он переносится вместе
  с сайтом, история не теряется.
